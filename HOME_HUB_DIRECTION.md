# Home Hub Direction

Status: derived AI-generation context. Not canonical. Sources: `HOME_SCREEN_PHILOSOPHY.md`, `HOME_SCREEN_DNA.yaml`, navigation artifacts, design DNA, motion, and interaction philosophy.

## Premise

The Home Hub is not a form, dashboard, feed, or chatbot. It is a calm intelligent hub that anticipates the current meal moment and receives new input without forcing the user to navigate.

The first impression should be: this app already understands the rhythm of my day.

## Stage And Console

The screen has two zones:

- Stage: upper roughly 70 percent. Quiet, spacious, atmospheric. Holds time-of-day heading and recurring meal cards.
- Console: lower roughly 30 percent. Permanent interaction zone. Holds the orb and input access.

The stage feels restful but ready. The console feels stable and thumb-reachable.

## Recurring Meal Section

Show 1-3 time-of-day recurring meal cards when known. Fewer cards means more space, not an empty failure. Cards should look like floating meal objects, not recommendations, ads, or feed items.

Tap flow:

1. User taps recurring card.
2. Card elevates into active meal card.
3. Previous portion is pre-filled.
4. User confirms.
5. Card dissolves into log memory.

This is the signature 2-tap flow.

## Orb Integration

The orb is always present in the console. It starts new input, communicates AI state, asks clarification, and becomes the result card. It should never feel like a generic add button or chatbot icon.

Input options appear from the orb area: voice, text, photo, barcode. Camera may open a focused modal, but returns to the home card loop.

## Bottom Console

The bottom console must support one-handed meal logging at a table:

- Large orb target.
- Clear input affordances.
- No tiny controls.
- Manual entry reachable.
- No full-screen form for primary logging.

The console is functional, not decorative.

## Emotional Atmosphere

The Home Hub should feel warm, quiet, and premium. Empty space is a valid state. No dashboard zeros, daily totals, progress rings, streaks, banners, or meal-history feed on first open.

Time is expressed through mood: "Morning", "Afternoon", "Dinner", not a clock-heavy dashboard.

## AI Invisibility

The Home Hub should show intelligence through behavior:

- Relevant recurring meals appear.
- Portion memory is pre-filled.
- The orb waits.
- Clarification is minimal.
- Results appear as structured cards.

Never announce "AI found..." or show a chatbot response. The AI is successful when the user notices the reduced effort, not the AI itself.

## Figma Generation Focus

For visual generation, prioritize the Home Hub as the anchor screen. Other screens should inherit its atmosphere, object hierarchy, and calm navigation model. If a generated screen feels like a dashboard, tracker, productivity app, or AI chat surface, it has drifted.
